 🌸 Pretty Calculator

A vibrant, highly interactive web-based calculator built with a focus on modern 3D mechanical physics, fluid hardware-accelerated animations, and a cute bubbly aesthetic. 

 ✨ Features

* **Bubbly UI Design:** Powered by custom rounded display typography and styled with an authentic, CSS-crafted decorative bow header.
* **3D Mechanical Physics:** True tactile button compression states (`:active`) that simulate physical key depth.
* **Cyberpunk Glow Effects:** A translucent frosted-glass layout container utilizing `backdrop-filter` paired with a neon display output module.
* **High Performance Engine:** Built using optimized Event Delegation to capture actions through a single DOM listener pool, minimizing runtime memory footprint.
* **Advanced Mathematics Tracking:** Safely processes standard numerical arithmetic alongside explicit exponent handling (`^` mapping to execution-safe `**`).

🛠️ Tech Stack

* **HTML5:** Semantic architecture optimized for client-side event routing.
* **CSS3 Grid & Flexbox:** Flat DOM column distribution for uniform layout scaling.
* **Vanilla JavaScript (ES6+):** Lightweight, asynchronous execution engine using centralized event delegation and `try...catch` error handling blocks.
